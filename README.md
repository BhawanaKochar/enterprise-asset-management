# Enterprise Asset Management System

An enterprise-grade Spring Boot Microservices application developed using Java 17 and Spring Cloud.

## Planned Architecture

- Eureka Discovery Server
- Spring Cloud Config Server
- Spring Cloud Gateway
- Authentication Service
- Asset Service

## Tech Stack

- Java 17
- Spring Boot
- Spring Cloud
- Spring Security
- JWT
- MySQL
- Docker
- Maven
- Git
- GitHub Actions
- Jenkins
- AWS EC2
